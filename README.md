## 国内节点还是香港/海外节点，先看三个硬指标

访客主要在国内、能等备案，选国内节点；不想备案或者客户在海外，选香港/海外。三个指标里，延迟反而是最不该纠结的那个。

**备案**：国内服务器必须备案，流程大约 15 天，要实名、拍照、上传身份证。港澳台和海外服务器免备案，这一步没有捷径。

**延迟**：国内机房全国 ping 基本在 50ms 左右；香港好线路 50–100ms；美西就算直连也要 150ms 上下。150ms 和 50ms 的差别，人眼感知没有数字看起来那么大，建站更该担心的是丢包和晚高峰绕路。

**带宽**：国内 5–10Mbps 建站就够用。海外标称 50Mbps、100Mbps 甚至 1Gbps 的不少，但多数是共享峰值，跑不满是常态。带宽除以 8 是理论最大下载速度：5Mbps 约 640KB/s，8Mbps 约 1MB/s，香港那档 2Mbps 约 256KB/s。

## 下单前最后确认的五件事

这几项比配置表更容易吃亏，付款前花两分钟过一遍。

1. **计费周期和续费价**。活动价多是 1–3 年打包，下单页会写到期续费的口径，翻一眼再付。
2. **带宽别买 1Mbps**。有站长买过 1Mbps 带宽的云服务器，结果图片稍多的网页都带不动，机器买贵了还得再升带宽。
3. **月流量额度**。轻量套餐带月流量包，超出后的计费或限速规则写在下单页，流量站要提前算。
4. **备份**。装好宝塔面板后设一个定时备份，网站文件和数据库分开备，别只靠服务商快照。
5. **基础安全**。禁止用 IP 直接访问网站，面板和程序版本及时更新，这两项能挡掉大部分扫描器。

## 常见问题

**1核2G 能跑 WordPress 吗？**
能跑，但插件多、图片多会吃力。动态站建议双核 + 2GB 内存起步，预算允许直接上 2核4G。

**腾讯云香港 2Mbps 够建站吗？**
文字和产品图为主的站够用，视频和大图库不够，配 CDN 能缓解一部分。

**建站一定要买高防吗？**
一般不用。没有商业竞争，很少有人会打你的站，省下这笔钱升级带宽更实际。

**国内服务器备案要多久？**
大约 15 天，需要实名、拍照、上传身份证。香港和海外服务器不需要这一步。

**轻量应用服务器和 CVM 差在哪？**
轻量把配置、带宽、流量打包，价格低、管理简单；CVM 弹性更强，但带宽单独计费，适合多站点和复杂架构。
